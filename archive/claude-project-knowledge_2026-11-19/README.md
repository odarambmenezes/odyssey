# Claude project knowledge files (removed 19 Nov 2026)

The 22 files that sat in the `claude` folder of the Claude "Odyssey" project's knowledge. Most were working reports auto-saved during chat sessions (audits, inventories, version notes, HTML prototypes of the Captain's Diary and the Odyssey packing list). They were removed from the project because project files act as instructions and compete with Notion (AI Project Instructions v1.1).

**These are reconstructions, not byte-exact originals.** Claude Projects does not allow downloading files, so a chat inside the project rewrote each document from what it could read. Two small files (`em-curso.md`, `registro-versao-candidata-2026-10-18.md`) were checked against the project and matched; the other 20 were not compared one by one. `diario-capitao-v16.html` was generated from v15 plus its differences, and `mala-da-odisseia-v7-candidata.html` from v6 plus its differences. Treat them as reference only.

Inputs worth keeping for the Skills phase: `inventario-bases-2026-11-11.md`, `pente-fino-skills-2026-11-11.md`, `reconciliacao-skills-mapping-2026-11-11.md`, `auditoria-task-backlog-2026-11-11.md`. `scan-impacto-o-hoje-2026-11-12.md` relates to 06 O Hoje (Chatty's work).
