## 🌟 Side Quest — Canonical MVP Definition

**Status:** 🟢 Approved

**Mission:** give Odara a new story to tell.

Side Quest is the operational interface to the **Side Quest On-Demand** engine. It should create a memorable experience, not optimize Odara's day.

### Interaction

Typical triggers:

- “Estou entediada…”
- “Me dá uma side quest pra hoje?”

The engine should not interrogate Odara before delivering the quest. It can use existing context silently and calibrate the delivery to the moment.

### Engine principles

- **Free mode:** organic randomness / Embrace the Chaos.
- **Anchored mode:** may use a Main Quest as an organic “holofote” rather than turning the Side Quest into another obligation.
- Mix internal inspiration and external discovery.
- Calibrate the **porte** of the quest at delivery based on current mood/context.
- Learn through Recap by surfacing patterns; do not silently rewrite preferences.
- Side Quest On-Demand and the Side Quest Generator use the same underlying engine.

### Experience principle

> **The Side Quest should not optimize Odara's day. It should make the day memorable.**
> 

The success test is emotional: did it make Odara want to actually live the experience?

### Visual direction

Mystical fortune-teller / crystal-ball / Magic 8 Ball energy, using the Odyssey Rune language. The Side Quest rune uses a quest/exclamation-mark visual language inspired by RPG quest markers without copying a specific game.

### Current status

MVP is defined and ready for real-use testing. Do not expand the engine or interface merely to make the system more complete.
